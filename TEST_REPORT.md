# Отчёт о проверках

## Автоматические

- `npm run typecheck` — пройдено (28 сентября 2026).
- `npm test` — пройдено: 5 из 5 тестов.
- `npm run build` — пройдено: production bundle собран (Vite 6.4.3).
- Стартовый экран production preview визуально проверен на desktop: русская копия, CTA, образец и placeholder камеры присутствуют.

Unit-тесты покрывают нейтральный Sigma, невозможность компенсировать gate бровей, отсутствие руки, повтор timestamp и большой разрыв tracking.

## Требует ручной live-проверки

В данной среде нет подтверждённой физической веб-камеры, поэтому не заявляется проверка живого MediaPipe. Нужно пройти: разрешение/отказ камеры, Sigma (нейтральное и правильное лицо), повороты обеих сторон, палец далеко/рядом/кулак/ладонь, уход из кадра, смену вкладки, timeout, полный забег и повтор без мыши. Отдельно: Chrome/Edge desktop, Android Chrome и iOS Safari при доступности. Проверить на трёх людях и двух вариантах обычного освещения.
