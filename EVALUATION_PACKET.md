# Пакет независимой оценки — MemeFace

Оценивать оба кандидата на одинаковом устройстве, освещении, времени и наборе участников; порядок прохождения чередовать. Сначала проверить минимум и воспроизводимость, затем достоинства. Не считать этот файл самооценкой.

| Вес | Критерий | Наблюдаемое доказательство | Балл |
| ---: | --- | --- | ---: |
| 30 | Работоспособность | Камера, полный забег, повтор, таймаут | |
| 20 | Режим ошибок | Ошибки для Sigma, поворота и пальца | |
| 20 | Техническая реализация | Локальный MediaPipe, worker, обработка stale данных | |
| 15 | UX/дизайн | Понятность без объяснения, desktop/mobile layout | |
| 10 | Оригинальность | Фотобудка, игровой сценарий | |
| 5 | Бонусы | Мобильная камера, доступность, debug | |

Протокол: отказать камере и восстановиться; выполнить нейтральное лицо, Sigma, оба направления поворота, правильный/неправильный палец, ладонь на старте и итогах; уйти из кадра, свернуть вкладку, дождаться таймаута. Зафиксировать устройство, браузер, свет и наблюдаемые сбои.
