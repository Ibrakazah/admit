# MemeFace — «Повтори мем»

Браузерная камера-игра: повторите Sigma и Mogger, получите одну конкретную подсказку и удержите позу. Это отдельный MVP для Admit Hackathon; проект не связан с PoseWall.

## Запуск

Требуется Node.js 20+.

```bash
npm ci
npm run dev
```

Проверки: `npm run typecheck`, `npm test`, `npm run build`, `npm run preview`.

Модели и WASM находятся в `public/`, поэтому при игре кадры не отправляются на сервер. Камера доступна на `localhost` и по HTTPS. Поддерживаются актуальные Chrome/Edge на ноутбуке и Android Chrome; iOS Safari нуждается в ручной проверке.

## Управление и проверяемые движения

| Движение | Условие | Действие |
| --- | --- | --- |
| Открытая ладонь | удержание в `ready` или на итогах | стартует/повторяет игру |
| Sigma | прищур + опущенные брови + удержание | завершает Sigma |
| Поворот головы | удерживается до порога yaw | открывает мишень пальца |
| Указательный палец у скулы | поворот сохранён, палец выпрямлен и в цели | завершает Mogger |

Кнопки дублируют действия для доступности и восстановления после ошибки. Телефон ставьте устойчиво: в Mogger нужна свободная рука.

## Правила и ошибки

Игровое совпадение строится по Face Landmarker blendshapes и геометрии landmarks, finger-to-cheek — по координатам изображения. Проходной порог 75/100, удержание 650 мс, гистерезис выхода 68. Один повторённый или просроченный кадр не заполняет удержание. Очки: `round(10 × stableAccuracy)`, максимум 2000 за забег. Sigma не использует руку.

Ошибка выбирается по приоритету: качество tracking, лицо в кадре, обязательный этап, ключевой признак, тонкая коррекция. Примеры: «Прищурься сильнее», «Поверни голову…», «Выпрями указательный палец», «Подними палец немного выше». Это игровая оценка движения, не оценка внешности, челюсти или личности.

`?debug=1` показывает возраст данных, inference duration, yaw, фазу и hold; он не изменяет правила.

## Ограничения и privacy

Нужна видимая голова и рука, нормальный свет и один игрок в кадре. Нет backend, учётных записей, отправки фото, видео и landmarks; `localStorage` хранит только будущий рекорд/настройки. Модели загружаются с сайта вместе с приложением. При отказе, занятой камере, неподдерживаемом браузере или ошибке модели доступен повтор.

Пороговые значения требуют живой настройки на разных людях и освещении. Нет заявлений о физическом касании щеки или универсальной точности. Будущий пользовательский жест из видео в MVP не реализован.
